# ml_modeling-foundations

A structured series of 22 Jupyter notebooks on core machine-learning methods in Python, primarily using scikit-learn, developed with teaching in mind.

The notebooks combine explanations of how each method works (its objective, assumptions and key parameters) with small computational experiments that show how modelling choices affect results. The emphasis is on understanding the reasoning behind the methods rather than treating models as black boxes.

The sequence of topics largely follows Müller and Guido, *Introduction to Machine Learning with Python* (O'Reilly). The notebooks add my own explanations of the underlying methods and further experiments.

## Topics

### Supervised learning

1. K-nearest neighbours
2. Linear regression and regularisation
3. Logistic regression and linear SVM
4. Naive Bayes
5. Decision trees
6. Random forests
7. Gradient boosting
8. Kernel SVM
9. Neural networks
10. Decision functions and predicted probabilities

### Unsupervised learning

11. PCA, NMF and t-SNE
12. K-means clustering
13. Agglomerative clustering
14. DBSCAN
15. Clustering evaluation and comparison

### Feature engineering and model evaluation

16. Feature engineering
17. Interactions and polynomial features
18. Transformations and feature selection
19. Cross-validation
20. Grid search and evaluation metrics

### Text analysis

21. Working with text
22. Topic modelling and document clustering

## Approach

Across the notebooks, reproducible examples are used to explore not only how to fit models, but also how choices about preprocessing, model specification, tuning and evaluation influence results.

## Tools

Python, scikit-learn, pandas, NumPy, matplotlib, Jupyter
